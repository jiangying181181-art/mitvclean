# 文档

## 电视端准备

不同品牌的入口位置不一样，但都需要先开开发者模式：

| 品牌 | 开发者模式 | ADB 开关 |
|---|---|---|
| 小米 / Redmi | 设置 → 关于本机 → 版本号 连按 7 次 | 设置 → 账号与安全 → ADB 调试 → 允许 |
| 华为 | 设置 → 关于 → 版本号 连按 7 次 | 设置 → 系统和更新 → 开发人员选项 → USB 调试 |
| 索尼 | —— | 需第三方工具（见下方说明）|
| 其他 Android TV | 设置 → 关于 → 版本号 / Build | 设置 → 系统 → 开发者选项 → USB 调试 / ADB 调试 |

**网络 ADB（端口 5555）**：

- 电视和电脑要在同一个局域网
- 国行小米每次重启后网络 ADB 会自动关闭，需要重新打开
- 首次连接电视会弹「允许 USB 调试吗？」，必须点**允许**

## 路由器 hosts 配置

### 小米路由器（AX3000 / AX6000 等，米家生态）

入口：**米家 App → 路由器 → 右上角 ⋯ → 路由应用 → 工具箱 → 自定义 Hosts**

> ⚠️ AX3000 的**网页版没有**这个功能（已实测：前端路由表里没有 hosts 页面），只能在 App 里。
>
> 格式是 **`IP地址 域名`**（IP 在前），与标准 hosts 相反。官方建议条目别设太多。

### 其他路由器

- 支持 OpenWrt 的：网络 → DHCP/DNS → 主机名 / 自定义 Hosts
- 爱快：网络设置 → DNS 设置 → 增加
- 华硕梅林：系统管理 → 系统设置 → JFFS + SSH，或用 AdGuard Home
- 通用做法：把生成的清单转成该路由器的"广告过滤 / 网址黑名单"条目

### AdGuard Home（推荐，能看到每个域名的拦截记录）

在 AdGuard Home 里加一条重写规则或用 hosts 语法导入。好处是**界面里能看到哪个域名被拦了**，
排查"为什么某个 App 打不开"很方便。

## 排查

### 连不上电视

```
1. ping <电视IP>           不通 → 不是同一个网络 / 电视关了
2. 电视上 ADB 调试开了吗   设置 → 账号与安全
3. 电视上点了「允许」吗     首次连接必弹
4. 电视 IP 变了吗          路由器可能重新分配，看 设置 → 网络
```

### 授权一直失败

电视上不弹「允许 USB 调试」时（部分国行固件会这样）：

```
1. 电视端把 ADB 调试 关 → 等 5 秒 → 再 开
2. 电脑端 adb disconnect <ip> → adb kill-server → adb start-server
3. 再 adb connect <ip>
```

### 禁完包桌面进不去

不应该发生（工具只禁清单里的包，不含桌面）。如果真发生了：

```
mitvclean --host <ip> restore
```

### 某个视频 App 打不开

hosts 拦过头了。找出对应域名删掉：

```bash
mitvclean --host <ip> scan          # 生成完整域名清单
# 看 report/domains.json，找该 App 的内容源域名，从 hosts 里删掉那行
```

### 贴片广告还在

广告按内容源动态下发，域名会变。所以要**定期重跑 scan**：

```bash
mitvclean --host <ip> scan
```

对比新旧清单，把新增的域名加进 hosts。

## 关于 Sony / LG / Samsung

- **Samsung Tizen**、**LG webOS**、**Fire OS** 不是 Android，ADB 方案不适用
- 索尼的 Android TV 机型 ADB 需要解锁 bootloader，风险高，不建议

## 安全须知

- ADB 调试开着 = 局域网上有个明文 shell，**用完请关**
- `pm disable-user` 是禁用不是卸载，随时可还原
- 改 hosts 前先备份路由器配置
